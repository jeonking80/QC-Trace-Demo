# 수작업 SQL

`V1/` 아래 파일은 마이그레이션 `StoredProcedures`가 포함 리소스로 읽어 실행합니다.
마이그레이션은 작성 시점 스키마를 고정해야 하므로, 이미 적용된 파일은 고치지 않고 `V2/`에 새 파일을 만들고 새 마이그레이션에서 실행합니다.

## 오류 번호 (THROW)

| 번호 | 의미 | 규칙 |
| --- | --- | --- |
| 50400 | 입력값 오류 (수량 0 이하, 알 수 없는 판정 등) | |
| 50403 | 작업자에게 필요한 역할이 없음 | |
| 50404 | LOT 또는 원 검사 행이 없음 | |
| 50409 | 같은 요청 키에 다른 본문 | R6 |
| 52001 | 승인 수량이 출하 가능 수량(합격 − 출하 − 예약)을 넘음. 미검사 수량은 승인 대상이 아님 | R1 |
| 52004 | 불합격·보류·정정에 사유 없음 | R4, R10 |
| 52005 | 검사자 본인이 자기 LOT 출하 승인 | R5 |
| 52007 | 출하 수량이 승인 잔량(예약)을 넘음 | R7 |
| 52011 | 정정 수량이 원 검사의 남은 수량 또는 현재 수량을 넘음 | R3 |
