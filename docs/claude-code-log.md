# Claude Code 작업 기록

[PLAN.md 8장](PLAN.md)의 작업 단위 10개를 Claude Code로 진행한 기록입니다. 기간: 2026-10-31 ~ 2026-11-01.

## 진행 방식

- **개발 세션**과 **검증 세션**을 나눴습니다. 개발 세션이 단위를 끝내면 패치와 설명을 넘기고, 검증 세션은 코드를 고치지 않고 실행 결과(테스트, 화면, DB 직접 조회)로만 확인했습니다. 검증 지적을 반영한 뒤 다음 단위로 넘어갔습니다.
- **규칙 테스트(단위 5)** 는 구현 코드를 보지 않는 별도 세션에서 PLAN 3장 규칙 표와 SP 계약서만 보고 작성했습니다. 개발 세션은 그 테스트 코드를 읽지 않고 결과만 받았습니다.
- 커밋은 단위마다 사용자가 결과를 확인한 뒤에만 했습니다.
- 업무 판단이 필요한 문제(아래 "사용자 결정")는 세션이 정하지 않고 사용자에게 물었습니다.

## E2E가 찾은 결함 (단위 10)

시나리오 2(불합격 재검사)에서, 전량 불합격된 LOT을 전량 재검사로 되돌리면 상태가 "검사 완료"로 남아 검사 화면 목록에서 사라지는 문제가 나왔습니다. 수량(미검사 20)은 맞았지만 다시 검사할 방법이 없었습니다. 상태 갱신 SP를 고치는 마이그레이션(`ReinspectStatus`, Data/Sql/V6)을 추가하고, 이미 그렇게 남은 LOT을 바로잡았으며, 회귀 테스트 2건을 넣었습니다. SP 단위 테스트와 규칙 테스트는 수량만 보고 상태 전이 후의 화면 동선은 보지 않아서 놓친 경우입니다.
